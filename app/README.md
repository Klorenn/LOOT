# Loot web app

Next.js app behind [findloot.xyz](https://www.findloot.xyz): landing, create, chest, explore, SDK pages and the API routes for the relayer, passkey wallets and chest metadata.

```bash
pnpm install
pnpm dev     # http://localhost:3000
pnpm test    # vitest
pnpm build
```

Configuration lives in `.env.local` (see [`.env.example`](.env.example)). Project overview, contracts and architecture: [root README](../README.md).
